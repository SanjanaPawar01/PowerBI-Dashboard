# Power BI Dashboard: Sales Analysis

This dashboard provides insights into sales data, using key performance indicators (KPIs) like total sales, profit, and product category performance. It includes the following visualizations:
- **Line Chart**: Sales trends over time.
- **Bar Chart**: Comparison of sales by category.
- **Donut Chart**: Distribution of profit by region.

### Key Insights:
1. The line chart shows an upward trend in sales during Q4.
2. The bar chart highlights that "Office Supplies" has the highest sales.
3. The donut chart shows that the "West" region generates the highest profit.

You can interact with the dashboard using the slicer for Region/Category.
